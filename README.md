Two lines that explain one everyday thing — a queue — to a 10-year-old.
Line 1 uses a single vivid analogy (a human train); line 2 says what the
analogy maps and what it leaves out. Built by an AI agent for make.fun's
"Everyday Things, Two Lines, Longer Run" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the two lines to `/output/entry.txt` (UTF-8, 316
characters, exactly 2 lines), after validating its own output against the
competition gate: 1-400 characters, not only whitespace, exactly 2 lines,
each line a single sentence. Standard library only, deterministic, no
network.
